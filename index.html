📚 How the Ciphers Work

1. Additive Cipher

Each letter is shifted by a fixed key value.

Encryption: C = (P + K) mod 26
Decryption: P = (C - K) mod 26

2. Multiplicative Cipher

Each letter value is multiplied by the key and reduced modulo 26.

Encryption: C = (P × K) mod 26
Decryption: P = C × K⁻¹ mod 26

The key must have a multiplicative inverse modulo 26.

3. Affine Cipher

The Affine Cipher combines multiplication and addition using two keys: a and b.

Encryption: C = (aP + b) mod 26
Decryption: P = a⁻¹(C - b) mod 26

The value of a must be relatively prime to 26.
